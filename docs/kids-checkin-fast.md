# LUNOR Kids — Check-in rápido

Escopo desta etapa:
- busca local por nome da criança;
- busca por nome/telefone dos responsáveis já vinculados;
- agrupamento visual de irmãos por responsável quando possível;
- preservar o check-in existente e as regras de retirada;
- sem nova tabela de famílias nesta fase.

A ausência de uma entidade `families` dedicada é intencional nesta etapa: o vínculo criança-responsável existente é suficiente para acelerar a recepção sem criar migração de dados prematura.
